# לוח שבועי לשער

אינטגרציית Home Assistant לניהול לוח פתיחה מקומי לשבוע הנוכחי באמצעות ישות Relay Mode קיימת של Palgate. התכנון נשמר ב־Home Assistant; הפקודות עצמן עדיין דורשות אינטרנט וענן Palgate.

## התקנה דרך HACS

1. ב־HACS פתח **Integrations → שלוש נקודות → Custom repositories**.
2. הוסף `https://github.com/kuperberg/weekly-gate-scheduler` מסוג **Integration**.
3. הורד את **Weekly Gate Scheduler** והפעל מחדש את Home Assistant.
4. עבור אל **הגדרות → מכשירים ושירותים → הוספת אינטגרציה** וחפש **לוח שבועי לשער**.
5. בחר את ישות `Relay Mode` של Palgate. היא חייבת לכלול `normal` ו־`hold_open`.

## הוספת הכרטיס

אם הופיעה הודעה על משאב Lovelace, הוסף את הכתובת שבהודעה כ־**JavaScript Module** תחת **הגדרות → לוחות בקרה → משאבים**. לאחר מכן הוסף כרטיס ידני:

```yaml
type: custom:weekly-gate-scheduler-card
entry_id: YOUR_CONFIG_ENTRY_ID
status_entity: sensor.YOUR_STATUS_ENTITY
```

`entry_id` מופיע בכתובת הדפדפן בעת פתיחת דף האינטגרציה. את חיישן המצב אפשר לבחור מתוך מכשיר **לוח שבועי לשער**.

## התנהגות

- הלוח תקף לשבוע הנוכחי בלבד ומתחיל ריק בכל שבוע.
- בכל יום ניתן להוסיף כמה אירועים עם סיום באותו יום או למחרת.
- אירוע שבת יכול להמשיך ליום ראשון עד שעת הסיום.
- הפעולות המהירות הן פתיחה עכשיו עד מחר ב־04:00, פתיחה עכשיו עד 17:00, וסיום פתיחה וחזרה ל־`normal`.
- המערכת בודקת את המצב מדי דקה ומנסה שוב לאחר תקלה.

## מגבלה חשובה

הסטטוס מאמת את מצב הממסר שאושר דרך אינטגרציית Palgate. הוא אינו חיישן פיזי למיקום השער.
